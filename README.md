Yanda Yarns - Read Me File

Yanda Yarns is an online e-commerce webapp. The inspiration is from a friend's crochet business. 
She makes crochet items and sells them to her customers. The platform allows users to browse through the catalogue of ready-made products.
Additionally, users can request items to be made for them based on a description given.


Tech Stack Used
HTML
CSS
JavaScript
Firebase Hosting
Node.js for deployment

How to run the webapp
Use the following link: https://mini-project-837cf.web.app

The Home/Index page opens.
A guest can view products, add to cart and add to wish list.
To view product details, click on the eye icon on the product card.
A guest cannot finalise their checkout process until they have logged in.
A signed in user can view their profile to see order history, wishlist and submitted requests.
Only logged in users can submit product requests.

An admin can log in and see the admin page.
They can manage products, view orders and view requests.
